JSONB

Du semi-structuré dans une base relationnelle

Pour les attributs variables ou rarement interrogés. Un index GIN sert l'opérateur de contenance @>.

CREATE INDEX idx_prefs_gin ON demo_preferences USING gin (prefs);

SELECT count(*) FROM demo_preferences
WHERE prefs @> '{"langue": "fr", "teletravail": true}';
-- Bitmap Index Scan on idx_prefs_gin  (50 002 lignes)

Une donnée interrogée, jointe ou contrainte reste dans une colonne typée.

PARTIE 2

Modéliser

MCD, MLD, formes normales, ORM

MCD

Le vocabulaire entité-association

  • Entité : objet identifiable de façon unique (salarié, département)
  • Association : lien sémantique (un salarié est affecté à un département)
  • Cardinalités (min, max) : participations d'une occurrence à l'association
  • Association porteuse : elle a ses propres propriétés (dates d'affectation)
  • Clé primaire identifie une ligne ; clé étrangère référence une autre table
Du MCD au MLD

Trois règles de passage

CasTraduction
Entitéune table ; l'identifiant devient la clé primaire
Association (x,1)–(x,n)clé étrangère dans la table du côté « 1 »
Association (x,n)–(x,n)une table ; clé primaire = les clés étrangères ; propriétés = colonnes
Normalisation

Formes normales, en bref

  • 1FN : valeurs atomiques (pas de liste dans une cellule)
  • 2FN : chaque colonne non clé dépend de toute la clé
  • 3FN : aucune dépendance entre colonnes non clés
  • Dénormaliser pour la performance : possible, si c'est documenté
  • Historiser par périodes [from_date, to_date) : la borne haute est exclue

Stockage

Ce qui se passe sous la table

  • Pages de 8 Ko ; lire toute la table = Seq Scan (salaries : 181 Mo)
  • MVCC : une mise à jour crée une nouvelle version de la ligne
  • VACUUM récupère l'espace ; ANALYZE calcule les statistiques
  • Après un chargement massif : VACUUM ANALYZE
  • TOAST : les grosses valeurs sont déportées et compressées
